# ALX Back end specialization course

This repository contains solutions and exercises for the ALX Backend JavaScript specialization. Each project focuses on a different aspect of backend development using JavaScript and Node.js.

## Projects

- **0x00-ES6_basic**: Introduction to ES6 features such as let/const, arrow functions, default parameters, rest/spread, destructuring, and template literals.
- **0x01-ES6_promise**: Working with JavaScript Promises, async operations, chaining, error handling, and utility methods.
- **0x02-ES6_classes**: Object-oriented programming in ES6, class syntax, inheritance, static methods, and advanced class features.
- **0x03-ES6_data_manipulation**: Advanced data manipulation in ES6, including arrays, maps, sets, and functional programming techniques.

- **0x04-TypeScript**: TypeScript basics, interfaces, classes, namespaces, and advanced typing.
- **0x05-Node_JS_basic**: Node.js basics, file I/O, HTTP servers, Express, and modularization.
- **0x06-unittests_in_js**: Unit and integration testing using Mocha, Chai, Sinon, and Express.

## Usage

Each project contains its own README and instructions. To run or test a project, navigate to its directory and follow the instructions provided.
