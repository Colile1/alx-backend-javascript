# 0x00. ES6 Basics

## Introduction
In this directory, I have implemented various tasks related to the basics of ES6 (ECMAScript 2015). These tasks are designed to help you understand the new features introduced in ES6, such as let/const, arrow functions, classes, and template literals.

## Installation
To get started, please ensure you have Node.js installed on your machine. You can download it from [nodejs.org](https://nodejs.org/).

## Usage
You can run the examples in this directory using Node.js. For example, to run the `1-block-scoped.js` file, you can use the following command:
```bash
node 1-block-scoped.js
```
