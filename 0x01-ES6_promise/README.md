# ES6 Promises

## Introduction
This directory contains implementations of various tasks related to JavaScript Promises and async/await functions. These tasks are designed to help you understand how to work with asynchronous operations in JavaScript.

## Installation
To get started, ensure you have Node.js installed on your machine. You can download it from [nodejs.org](https://nodejs.org/).

## Usage
You can run the examples in this directory using Node.js. For example, to run the `4-user-promise.js` file, use the following command:
```bash
node 4-user-promise.js
```
