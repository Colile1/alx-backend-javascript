# ES6 Data Manipulation

This folder contains a series of JavaScript exercises focused on data manipulation using ES6 features. The exercises primarily work with student data and demonstrate various techniques such as array methods, sets, typed arrays, and weak collections.

## Files Overview

- `0-get_list_students.js` - Returns a list of student objects with id, firstName, and location.
- `1-get_list_student_ids.js` - Extracts an array of student IDs from a list of students.
- `2-get_students_by_loc.js` - Filters students by their location (city).
- `3-get_ids_sum.js` - Sums the IDs of students in a list.
- `4-update_grade_by_city.js` - Updates student grades based on their city.
- `5-typed_arrays.js` - Demonstrates usage of typed arrays in JavaScript.
- `6-set.js` - Demonstrates usage of the Set object for unique values.
- `7-has_array_values.js` - Checks if an array contains certain values.
- `8-clean_set.js` - Cleans or modifies a Set object.
- `9-groceries_list.js` - Manipulates a groceries list using ES6 features.
- `10-update_uniq_items.js` - Updates unique items in a collection.
- `100-weak.js` - Demonstrates usage of WeakSet or WeakMap for weak collections.

## Usage

These exercises are designed to be run in a Node.js environment. Each file exports a function that can be imported and tested independently.

## Purpose

The goal of these exercises is to practice and understand ES6 data manipulation techniques, including array methods, sets, typed arrays, and weak collections, through practical examples.
